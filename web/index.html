Table help

First calling round: a plain suit symbol orders the dealer to pick up the shown suit; the same suit inside a ring orders it up and means you go alone. Second calling round: a plain suit symbol calls that suit; a ringed suit calls it and means you go alone. Target: show current state. Rabbit and top hat: show the last trick. The gold halo marks the dealer; the cyan border marks the active player. When a player goes alone, that player's partner sits out. Bot data only is the default and uses faster visual pacing. My performance records the owner's results and uses VoiceOver pacing. Peter narration waits for each recording to finish at either tracking setting.
