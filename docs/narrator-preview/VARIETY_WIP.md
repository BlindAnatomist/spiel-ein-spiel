## Provisional content and longevity plan

The working capacity is 168 new contextual lines, yielding 196 character choices
with the existing 28. This is a planning budget, not a quota or approved script
catalog. Common contexts receive most of the reserve; rare sweeps and lone bids
receive fewer. Drafts must have a specific comic premise and recognizable spoken
character logic, rather than cosmetic paraphrases or disconnected crude imagery.

Prepared-metadata capacity simulations use actual game events, but not finished
scripts or recordings. The provisional targets are three to four remarks per
hand on average, at least 90 percent distinct across the first two games, 75
percent across five, and 50 percent across ten. Exact repeats within a game or
the preceding two completed games are prohibited. If no suitable line is ready,
the event remains factual. These targets require validation with the final
approved script and audio catalog before publication.
